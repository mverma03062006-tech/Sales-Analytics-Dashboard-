## 📌 Project Overview

The Sales Analytics Dashboard transforms raw sales data into meaningful business insights through automated preprocessing, statistical analysis, interactive KPIs, and data visualization.

Users can upload their own datasets, clean and prepare the data, explore sales performance, identify trends, and download processed datasets.

The application is designed to simplify exploratory data analysis and make business analytics more accessible through an intuitive web interface.

## ✨ Key Features

### 📂 1. Multiple Dataset Upload

- Upload CSV files.
- Upload Excel files.
- Upload JSON files.
- Analyze different datasets through a single interface.

### 🧹 2. Data Preprocessing

- Data validation.
- Missing value detection and handling.
- Duplicate record identification and removal.
- Data cleaning and preprocessing.
- Prepare datasets for further analysis.

### 📈 3. Dynamic KPI Analysis

- Five dynamic KPI indicators.
- Real-time metric updates.
- Interactive filtering for focused analysis.

### 📊 4. Interactive Visualizations

- Interactive charts using Plotly.
- Explore sales patterns and trends.
- Visual analysis of business performance.
- Dynamic visualizations based on selected filters.

### 📉 5. Statistical Analysis

- Statistical summaries.
- Exploratory data analysis.
- Understand patterns and distributions in sales data.

### 📥 6. Data Export

- Download cleaned and processed datasets.
- Reuse processed data for further analysis.

## ⚙️ Installation and Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/mverma03062006-tech/Sales-Analytics-Dashboard-.git
```

### 2. Navigate to the Project Directory

```bash
cd Sales-Analytics-Dashboard-
```

### 3. Create a Virtual Environment

**Windows:**

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**Linux / macOS:**

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 4. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 5. Run the Application

```bash
python -m streamlit run app.py
```

The application will be available at:

```text
http://localhost:8501
```
